03 How it fits together

A request comes in, and a router decides where it should run — local first when the local hardware can do the job well, cloud when it can't. Everything gets logged: which machine, which model, how long, what it cost. That accounting is the point — I can't improve what I can't measure.

On top of that sits Karakuri, a software factory where agents pick up a task, route it through a pipeline, and hand back something built and graded. The whole thing is config-driven and observable — which is really just the tester's instinct applied to infrastructure.
